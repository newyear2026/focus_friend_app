The HTML snapshots in this folder preserve the source's license statement and creator-provided recording descriptions. `files.json` records the public preview URL, SHA-256, file size and verification date for each unmodified bundled file. No modifications or sample extraction were applied to these MP3s. Looping, volume control and the 800 ms end-of-session fade are performed during playback. The Settings screen provides selectable source and license URLs as a courtesy credit.

The app does not claim ownership of these recordings. CC0 permits commercial use, editing and distribution, but a license label cannot independently guarantee that the uploader held every relevant right. The selected source pages identify the recording and its creator, and do not describe sampling third-party music.
