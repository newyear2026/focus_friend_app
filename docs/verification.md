## 직접 실행 증거

스크린샷과 저장소 스냅샷은 이 작업의 `screenshots/`, `verification/` 폴더에서 수집합니다. 스냅샷은 개발 앱의 SQLite DB를 읽기 전용으로 복사한 것이며 타이머를 앞당기기 위해 DB나 시스템 시각을 수정하지 않았습니다. 새 앱 전용 검증 데이터는 남겨 두고 기존 앱 데이터는 건드리지 않았습니다.

프로세스 종료 전후 일시정지 스냅샷은 정확히 동일했고, 세션 ID·실제 진행 26.427초·잔여 273.573초를 유지했습니다. 재개는 같은 ID를 쓰고 남은 273.573초만 새 종료 시각에 더했습니다. 백그라운드에서 새 앱의 실제 PID를 종료한 뒤 프로세스가 사라진 것도 확인했습니다.

알림은 `RTC_WAKEUP` 부정확 알람으로 등록되었으며, 시스템 진단은 요청 종료 시각 뒤 약 3분 25초의 추가 전달 윈도우를 표시했습니다. 이 관찰 자체가 시제품 알림의 정확성을 보장하지 않습니다. 강제 종료(force-stop)와 재부팅 뒤 알림은 보장하지 않습니다.

검증 중 확보한 사진은 전체 목업이나 합성 이미지가 아니라 에뮬레이터 `screencap` 원본입니다. 참고 이미지 접근 실패 때문에 원본과의 시각적 일치 여부는 검증하지 못했습니다.

디버그 APK의 권한은 Flutter 개발 연결용 INTERNET, 선택적 POST_NOTIFICATIONS, AndroidX 내부 수신기용 앱 전용 서명 권한입니다. SCHEDULE_EXACT_ALARM/USE_EXACT_ALARM/절전 예외/저장소 접근 권한은 없습니다.
