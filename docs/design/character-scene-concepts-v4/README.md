# 사막여우의 노을빛 서재

2026-10-14. 사용자 요청에 따라 새 사막여우 캐릭터를 Focus Friend의 부드러운 2D 그림체와 타이머 화면 구도로 그린 정적 이미지 시안입니다. 기존 Sobrita와 routine_app의 현재 캐릭터 목록에서 사막여우를 찾지 못해 이번에는 새 디자인으로 제작했습니다. built-in ImageGen을 사용했습니다.

- 원본 PNG: [fennec-fox.png](fennec-fox.png)
- 실제 사용한 전체 프롬프트: [fennec-fox.prompt.txt](fennec-fox.prompt.txt)

실제 첨부한 참고 이미지는 현재 앱 구도 `../calm-connected-motion/home-evening.png`와 승인된 그림체 `../immersive-room/reference.png`입니다. 두 참고의 랫서팬더는 구도와 그림체 참고이며, 사막여우의 원본 캐릭터로 사용하지 않았습니다.

결과를 직접 확인했습니다. 큰 삼각형 귀, 모래빛 털과 크림색 가슴, 작은 주둥이와 어두운 코, 복슬복슬한 꼬리로 사막여우를 표현합니다. 연결된 앞발로 노트에 필기하며, 창밖에는 모래언덕·오아시스·노을이 보입니다. 실내에는 따뜻한 나무 책상과 조명, 다육식물·선인장·도기 소품을 배치했습니다. 타이머·시간 선택·시작 버튼·세 하단 탭을 유지합니다.

현재 앱과 캐릭터 선택은 변경하지 않았으며 애니메이션 프레임은 제작하지 않았습니다. 실제 적용 시 UI는 앱 코드로 렌더하고, 배경·캐릭터·소품을 별도 에셋으로 제작합니다.
