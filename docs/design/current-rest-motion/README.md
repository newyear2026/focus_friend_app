# 현재 휴식 모션 미리보기

현재 Flutter 앱의 저녁 휴식 화면을 실제 앱 위젯과 `RestCompanionPainter`로 렌더했습니다. 사용자 저장소에 접근하지 않는 메모리 저장소를 사용합니다.

- 화면 390×844, 캡처 780×1688. Pretendard와 Material Icons 폰트를 로드했습니다.
- `RestAnimation.timeline`의 120틱을 12fps로 렌더해 10초 전체 주기를 캡처했습니다. 추가 마지막 캡처에서 기본 자세로 돌아오는 것을 확인합니다.
- 모든 캡처의 프레임 번호가 현재 앱 타임라인과 일치하며, 14개 그림이 모두 표시됩니다.
- 모션은 1배 속도입니다. 휴식 타이머는 미리보기에서 05:00에 고정했습니다.
- 현재 몰입형 화면은 쿠션과 다리를 잘라 책상 앞 상반신과 찻잔을 표시합니다. 책상 위 닫힌 책은 고정되어 있습니다.

실행: `flutter test --no-pub tool/capture_current_rest_test.dart`

`rest-full-cycle.mp4`는 120개 캡처로 인코딩한 10초 영상이며, `rest-full-cycle.gif`는 같은 전체 주기의 반복 미리보기입니다. 에뮬레이터 실시간 녹화가 아닙니다.
