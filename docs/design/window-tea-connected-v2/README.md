# 연결 원화로 바꾼 사막여우 · 다람쥐 휴식

두 캐릭터의 휴식 동작을 랫서팬더처럼 **완성된 연결 원화 한 장씩 재생하는 방식**으로 교체했습니다. 기존의 컵 위치 메쉬 보정, 두 원화 혼합, 머리/몸을 다르게 전환하는 처리를 제거했습니다. 이 변경은 휴식 시간과 친구 미리보기에 적용됩니다.

[움직이는 비교 화면](http://127.0.0.1:8127/docs/design/window-tea-connected-v2/) · [사막여우 22초](fennec.mp4) · [다람쥐 22초](squirrel.mp4) · [수정 전 비교](../rest-motion-comparison-v1/)

## 동작과 작화

- 각 캐릭터 4×4, 16칸의 새 원화. 기본 자세 중복 칸 하나를 제외한 15칸을 사용합니다.
- 기본 자세의 눈 뜸/반쯤 감음/감음, 잔을 조금씩 드는 11개 연결 자세, 눈을 감고 한 모금 마시는 자세입니다.
- 12fps는 타이밍 격자이며 초당 12개의 새 그림을 뜻하지 않습니다. 올림과 내림은 한 자세에 4틱을 배정해 일정한 간격으로 재생합니다. 내림은 올림의 역순입니다.
- 전체 22초: 창밖 보기와 눈 깜빡임 5초 → 약 3.7초간 올림 → 한 모금/전후 머무름 약 1.8초 → 약 3.3초간 내림 → 눈 깜빡이며 휴식. 시작과 끝은 정확히 같은 기본 원화입니다.
- 긴 대기 중에도 세 차례 눈을 깜빡입니다. 반복 경계를 포함해 같은 그림으로 머무는 최대 구간은 5초입니다.
- 몸통·어깨·팔·손·잔은 연결된 원화입니다. 얼굴/귀/모자와 몸 크기를 기준으로 원화 전체에 균일한 크기/위치 정렬만 적용했습니다. 런타임에는 머리나 팔을 따로 자르거나 늘리지 않습니다.
- 책과 연필은 이전 기본 원화에서 추출한 같은 전경을 모든 칸에 넣어 고정했습니다. 기존 아침·낮·저녁·밤의 빈 방은 유지합니다.

연결 원화 특유의 작은 선/질감 차이는 남습니다. 두 그림을 섞어 가짜 중간 자세를 만들지 않으므로 컵·팔의 이중 윤곽은 없습니다. 캐릭터 화면 크기는 기존 앱 배치를 유지했으며, 랫서팬더의 10초 타이밍과 화면 크기를 복사한 것은 아닙니다.

## 제작과 파일

이미지는 **built-in ImageGen 편집 모드**로 만들었습니다. 원본과 최종 요청문은 이 폴더의 `fennec-rest-raw.png`, `squirrel-rest-raw.png`, `fennec-rest.prompt.txt`, `squirrel-rest.prompt.txt`입니다. [원본·참고 이미지·최종 자산 기록](asset-manifest.json)을 함께 보관했습니다.

`tool/package_connected_window_tea.py`는 원화 칸 자르기, 이웃 칸에서 넘어온 분리된 가장자리 조각 제거, 전체 그림의 균일한 크기/위치 정렬, 고정 소품 포장만 수행합니다. 그림이나 신체 부위를 새로 그리지 않습니다.

앱 자산:

- `assets/images/friends/motion/fennec/rest.png`
- `assets/images/friends/motion/squirrel/rest.png`

각 자산은 1536×1536px 투명 PNG이며 한 칸은 384×384px입니다. [사막여우 원화 비교](fennec-contact.jpg), [다람쥐 원화 비교](squirrel-contact.jpg), 실제 동작 구간 비교 [사막여우](fennec-action-contact.jpg) / [다람쥐](squirrel-action-contact.jpg)를 보관했습니다.

## 확인

전체 테스트 97개 통과, 실제 전체 앱 캡처 테스트 1개 통과, 정적 분석 이상 없음, Android 디버그 APK 빌드 성공입니다. 테스트는 반복 경계, 눈 깜빡임과 최대 정지 구간, 고정된 책 픽셀, 일시정지/재개, 화면 비활성화, 동작 줄이기, 방 전환 시 모션 보존과 기존 펭귄·해달 동작을 확인합니다. 테스트 통과와 별도로 전체 22초의 올림·마심·내림·반복 경계 영상을 검토했습니다.

[전체 테스트](tests.log), [분석](analyze.log), [빌드](build.log), [실제 앱 캡처](capture.log), [시각 시계/원화별 캡처 근거](capture-manifest.json)를 참고하세요. 영상은 실제 FocusFriendApp을 같은 화면 크기와 저녁 시간에 캡처했고 속도를 변경하지 않았습니다. 원화 제작 이미지를 단순히 움직여 만든 시안 영상이 아닙니다.

앱의 휴식 미리보기는 **친구 → 다람쥐/사막여우 → 미리보기**에서 볼 수 있습니다. 선택한 친구로 휴식 시간을 시작하면 같은 모션을 사용합니다.

에뮬레이터 `emulator-5554` 설치본을 업데이트했고, 설치 APK의 두 원화가 작업 자산과 바이트 단위로 같음을 확인했습니다. 업데이트 전후 저장 JSON은 완전히 같으며 revision 30, 기록 4개가 유지됩니다. [데이터 보존 기록](data-preservation.json), [검증 결과](verification.json)
