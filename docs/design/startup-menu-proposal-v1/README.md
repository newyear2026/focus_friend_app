# 재실행 후 하단 메뉴 유지 시안

2026-11-05. **이미지 제안 단계이며 앱 코드에는 아직 반영하지 않았습니다.**

![일시정지 상태에서도 하단 메뉴를 표시하는 시안](proposal.png)

## 확인한 현재 동작

- 세션이 없는 새 실행에서는 책상·친구·기록·설정 메뉴가 표시되고 탭 전환이 가능합니다.
- 저장된 세션을 복원하면 `active != null` 조건으로 메뉴를 숨깁니다. 일시정지와 완료 확인 전 상태도 포함됩니다.
- 에뮬레이터 재실행 시 `24:59` 일시정지 상태와 메뉴 숨김을 확인했습니다.
- 메모리 저장소를 사용하는 임시 위젯 테스트 2개로 새 실행의 네 탭 전환, 일시정지 복원, 종료 확정 후 메뉴 복귀를 확인했습니다. 임시 테스트는 검증 후 삭제했고 기기의 기존 세션은 종료하지 않았습니다.

## 제안하는 동작

- 앱 재실행과 세션 복원 후에도 하단 메뉴를 유지합니다.
- `24:59`, 일시정지 상태, ‘이어서 집중’과 ‘이번 시간 종료’ 버튼을 보존합니다.
- 다른 탭으로 이동한 뒤 책상으로 돌아와도 같은 세션을 유지합니다.
- 구현 시 메뉴 표시 조건뿐 아니라 세션이 있으면 책상을 강제 표시하는 조건도 함께 변경해야 합니다.
- 세션 중 새로 접근 가능한 친구 적용과 새 타이머 시작은 기존 세션과 충돌하지 않도록 처리해야 합니다. 구체적인 동작과 구현은 아직 확정하지 않았습니다.

## 이미지 생성

기존 일시정지 화면을 편집 대상으로, 사용자가 첨부한 기본 책상 화면을 하단 메뉴 참고로 사용했습니다. built-in Image Gen으로 만든 미리보기이며 실제 앱 실행 화면이 아닙니다. 생성 프롬프트는 [prompt.txt](prompt.txt)에 보관합니다.
