3Android 에뮬레이터에서 확인

Pixel_3 에뮬레이터에서 단계마다 안드로이드 창 정보를 직접 읽어, 화면 켜두기 표시(KEEP_SCREEN_ON)가 실제로 붙었는지 확인했습니다. 별도 검증용 패키지를 썼고, 설치된 개발 중인 앱은 그대로입니다.

단계창의 화면 켜두기 표시
스위치 켜기 전없음
스위치만 켬 (타이머 시작 전)없음
집중 중있음
일시정지없음
재개있음
종료없음

휴식은 에뮬레이터에서 따로 돌리지 않았습니다. 집중과 같은 조건(타이머 진행 중)을 쓰고, 위 2번 흐름과 자동 테스트에서 확인했습니다.
