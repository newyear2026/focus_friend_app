5번 · 테스트 보강 계획 시안

제품 코드는 바꾸지 않고, flutter test(몇 초면 끝나는 평소 테스트)가 앱 화면의 애니메이션을 실제 프레임으로 확인하게 만드는 계획입니다.

1지금 테스트가 덮는 범위

애니메이션 테스트는 세 층으로 나뉩니다. 비어 있는 곳은 가운데 층입니다.

앱 화면 테스트

widget_test
실제 앱 화면과 버튼으로 집중을 시작·멈춤·재개합니다. 그런데 그림을 불러오지 않아 대체 그림 1장만 보여서, paused·animate 같은 설정값만 확인합니다. 앱이 캐릭터에 신호를 잘못 넘겨도 실제 프레임이 멈추는지는 모릅니다.

느림

지난번에 "일시정지 동작이 망가져도 테스트가 못 잡는다"고 했는데, 정확히는 캐릭터 자체는 단독 테스트가 잡습니다. 못 잡는 건 앱 화면 → 캐릭터 연결이 잘못된 경우입니다. 실제로 main.dart의 studying:을 일부러 false로 바꿔 집중 중에도 캐릭터가 필기하지 않게 만들어 봤는데, 테스트 43개가 모두 통과했습니다. (확인 후 원래대로 되돌림)

// test/companion_art.dart (새 파일)
Future<void> precacheCompanionArt(WidgetTester tester) => tester.runAsync(() async {
  final context = tester.element(find.byType(Scaffold).first);
  for (final asset in [bodyAsset, notebookAsset, RestAnimation.asset, RestAnimation.inbetweensAsset]) {
    await precacheImage(AssetImage(asset), context);
  }
});
int studyFrame(WidgetTester t) => (t.widget<CustomPaint>(find.byKey('reference-companion-cels')).painter!
    as ReferenceCompanionPainter).frame;

// widget_test.dart — ① 집중 흐름
await tester.tap(find.text('잠시 멈추기'));
final held = studyFrame(tester);
await tester.pump(const Duration(seconds: 3));
expect(studyFrame(tester), held);              // 지금: expect(companion().paused, isTrue)
