친구 기능 점검 · 결정이 필요한 3가지

타이머·저장 로직에는 오류가 없었습니다. 아래는 새로 생긴 친구 기능에서 발견한 점이고, 화면은 모두 지금 코드로 렌더링한 실제 캡처입니다.

1친구 방에는 소품이 처음부터 그려져 있음 해금 규칙과 어긋남

아직 아무것도 모으지 않은 새 사용자(오늘의 집중 0분) 화면입니다. 랫서팬더 방은 책상이 비어 있지만, 펭귄 방에는 조명·화분·머그컵이 그림 자체에 들어 있어 첫날부터 보입니다. 반대로 실제로 모은 소품은 친구 방에 놓이지 않습니다.

펭귄 · 해달 · 다람쥐 · 사막여우 방 모두 같은 구성입니다. 또 각 방은 시간대가 고정이라(펭귄은 저녁, 해달은 낮…) 아침·낮·저녁·밤에 따라 바뀌지 않습니다.

A. 안내만 바로잡기 (추천)

친구 방은 "꾸며진 방"으로 두고, 소품 모으기는 랫서팬더 방의 재미로 안내합니다. 소품 화면 문구를 "소품은 랫서팬더의 방에 놓여요"로 바꿉니다.

작업: 문구 4개 언어 · 바로 가능

B. 친구 방도 해금에 맞추기

네 장의 그림에서 조명·화분·머그컵을 지우고, 모은 소품을 각 방 책상 위치에 맞춰 코드로 올립니다.

작업: 그림 4장 수정 + 친구별 위치 · 규모 큼

C. 친구를 해금 보상으로

소품을 다 모으면 친구가 열리는 식으로, 친구 방의 소품을 "다 모은 방"의 모습으로 의미를 바꿉니다.

작업: 친구 잠금 규칙 추가 · 기획 결정 필요

2완료 알림이 늘 랫서팬더를 부름 바로 고칠 수 있음

펭귄을 고른 사용자가 집중을 마쳤을 때 받는 알림입니다. 알림 문구가 고정이라 4개 언어 모두 랫서팬더로 나옵니다. 알림을 만들 때 이미 저장된 상태를 읽고 있어서, 고른 친구 이름을 넣기 쉽습니다.

3"모은 소품" 화면은 늘 랫서팬더 방 1번과 함께 결정

펭귄을 고른 상태에서 설정 → 모은 소품을 열었을 때입니다. 소품을 보여 주는 방이 랫서팬더 방뿐이라 의도된 것일 수 있지만, 아래 안내 문구는 "내 방에 놓인다"고 읽힙니다.

펭귄 선택 중위: 랫서팬더 방 · 아래: "소품은 자동으로 자리에 놓여요"
