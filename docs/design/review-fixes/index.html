3시간대가 바뀔 때 책 부분만 먼저 바뀜 화면

저녁→밤 전환 1초째(2초 중 절반) 화면입니다. 배경은 절반쯤 바뀌었는데, 앞쪽 책 부분(빨간 선)은 이미 완전히 밤이라 경계가 보입니다.

고치는 방법 · 책 이미지도 같은 AnimatedSwitcher로 감싸거나, 배경과 책을 한 레이어로 묶어서 함께 바꿉니다. (study_scene.dart:243)

4휴식 화면에서 조명·책만 밤 색조가 빠짐 화면 · 의도 확인 필요

밤 시간대 휴식 화면입니다. 화분과 머그컵에는 밤 색조가 들어가는데, 조명과 덮인 책에는 들어가지 않아 조금 더 밝게 떠 보입니다. 조명은 빛나는 물건이라 일부러 뺐다면 그대로 두셔도 됩니다.

고치는 방법 · 두 Image.asset에 다른 소품처럼 color: _foregroundTint, colorBlendMode: BlendMode.modulate를 넣습니다.

5테스트가 애니메이션 동작을 확인하지 못함 테스트

테스트 환경에서는 그림 파일이 로드되지 않아 애니메이션이 아예 시작되지 않습니다. 그래서 지금 테스트는 설정값만 확인합니다.

지금 확인하는 것

✓멈추기를 누르면 paused = true가 전달됨
✓캐릭터 위젯이 다시 만들어지지 않음
✗멈춘 동안 그림 프레임이 정말 멈추는지
✗다시 시작하면 프레임이 이어서 움직이는지

고친 뒤

+테스트에서 작은 가짜 이미지를 미리 넣어 애니메이션을 실제로 돌림
+ReferenceCompanionPainter.frame 값이 멈춤 동안 같고, 재개 후 바뀌는지 확인 (예전 테스트가 하던 일)

6화면을 그릴 때마다 전체 상태를 복사 성능 · 예전부터 있던 구조

engine.state는 읽을 때마다 기록 최대 100개를 포함한 상태 전체를 JSON으로 만들었다 되돌립니다. 집중 중에는 0.25초 타이머와 화면 그리기에서 계속 불립니다.
