## 테스트 도구의 삭제 동작과 복구

이번 작업에서 `flutter test integration_test`가 종료 시 앱을 제거해 개발 앱의 5분 검증 기록을 지운 문제가 발생했습니다. 사용자에게 즉시 알렸고, 이전에 확보했던 `/Users/jaewook/Documents/Codex/2026-10-07/task/verification/final-home.db`의 원래 SQLite 스냅샷으로 복원했습니다. 새 세션이나 임의 집계를 만들어 복구하지 않았습니다.

Flutter는 테스트 시작 전 기존 APK에서 종료 시 삭제할 패키지를 읽습니다. 따라서 식별자를 바꾸는 것만으로는 부족하며, `tool/verify_android.py`가 먼저 `.verification` APK를 빌드한 뒤 같은 식별자로 테스트합니다. 일반 앱과 검증 앱의 설치 영역을 분리했습니다. 테스트용 화면은 메모리 저장소, SQLite 테스트는 검증 앱의 verification.db를 사용합니다.

격리 실행기로 Android SQLite 테스트 1개를 실행한 뒤 일반 앱만 설치되어 있고 검증 앱은 제거되었음을 확인했습니다. 종료 후 일반 앱 DB를 다시 읽어 이전 final-home.db와 SHA-256이 완전히 같음을 확인했습니다. 정상 완료 1회·300000ms·화분·원래 세션 ID와 완료 시각·active=null 보존. 알림 허용 상태도 복원했습니다. `final-home-native.png`에서 현지 저녁 화면·오늘 5분·화분을 직접 확인했습니다.

현재 범위에 미해결 P0/P1/P2 없음. 테스트 도구의 패키지 삭제 문제는 복구와 재발 방지 후 실제 종료 동작까지 확인했습니다.
