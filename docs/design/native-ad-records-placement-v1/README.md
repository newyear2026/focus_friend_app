# 월간 기록 네이티브 광고 배치 시안

현재 월간 기록 화면의 `가장 많이 한 날` 아래에 네이티브 광고 카드 한 개를 배치한 이미지 시안입니다. 기록 내용과 함께 스크롤되는 배치이며, 하단 메뉴와 간격을 둡니다.

- 결과: [month-native-ad.png](month-native-ad.png)
- 원본 화면: [month.png](../records-stats/month.png)
- 생성 프롬프트: [prompt.txt](prompt.txt)
- 제작: 내장 ImageGen으로 기존 화면 편집

`광고` 배지와 광고 정보 아이콘을 표시했습니다. 광고주, 노트 사진과 문구는 가상 예시입니다. 실제 광고 내용과 광고 정보 UI는 사용하는 광고 SDK의 사양에 맞춰 표시해야 합니다.

앱 코드와 광고 SDK는 변경하지 않았습니다. 이 이미지는 배치 검토용이며 실제 SDK 연동이나 정책 검증을 의미하지 않습니다.
