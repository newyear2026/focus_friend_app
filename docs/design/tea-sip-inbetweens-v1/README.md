# 다람쥐·사막여우 마시기 연결 원화

기준: `37cf920` / 작업 브랜치: `feat/tea-sip-inbetweens`. 다른 요청의 리듬 변형은 포함하지 않았습니다.

기존 셀10 편집을 통해 친구마다 A(셀3), B(셀27), 셀17·18·16 다섯 장을 만들었습니다. 내장 ImageGen을 사용했고, 원문 프롬프트·입력·도구 원본 경로는 [편집 기록](prompts/imagegen-manifest.json)에 있습니다. 프로젝트에서 사용하는 최종 원화는 `assets/images/friends/motion/{fennec,squirrel}/rest.png` 입니다.

귀·꼬리·등·도토리 모자·가방의 고정 영역은 셀0 픽셀을 그대로 합성했습니다. 셀10의 기존 경계 주변을 가드로 보존하고 안쪽 편집을 마스크 알파 전이로 합성했습니다(384px에서 Gaussian radius1.5, 512px 기준 반경2px). 그림 내용의 블러, 파츠 변형·워핑·별도 회전은 사용하지 않았습니다. 마시는 셀도 예외 없이 같은 고정 영역을 적용합니다.

10 → A(2틱) → B(2틱) → 17(3틱) → 18(3틱) → 16(18틱)으로 이어지고 역순으로 돌아옵니다. 늘어난 8틱을 휴식에서 줄여 22초·264틱을 유지했습니다. 두 반복 경계를 포함한 같은 그림 최대 유지는 60틱입니다.

[원화 측정 도구](package_and_measure.py), [사막여우 전체값](fennec-art-measurements.json), [다람쥐 전체값](squirrel-art-measurements.json).

컵 높이는 같은 크림색 연결 영역의 최상단을 일정하게 측정했습니다(작을수록 높음). 사막여우 셀10과 A는 같은 높이에서 눈꺼풀·컵 각도가 바뀌고 다음 B에서 입으로 올라갑니다. 값은 역방향으로 내려가지 않습니다.

연속 컷은 실제 앱의490×462 캡처에서 RGB 채널 최대 차이로 계산했습니다. 동일한 캡처·계산으로 랫서팬더의 최대치는 **차이>0: 48,101픽셀 / 차이>15: 21,210픽셀**이며, 두 친구는 두 기준 모두 랫서팬더보다 작습니다. 요청서의 ‘약21,600픽셀’은 차이 임계값이 생략되어 있어 엄밀한0초과 수치로는 재현되지 않습니다. **0초과에도21,600을 절대 상한으로 적용하면 사막여우41,749·다람쥐25,445는 통과하지 못합니다.** 15초과 값을0초과 값처럼 표시하지 않았습니다.
