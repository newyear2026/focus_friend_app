# 로딩 캐릭터 모션 시안 두 가지

사용자가 요청한 두 모션을 각 3컷 정지 이미지로 표현했습니다. built-in Image Gen을 사용했고, 기존 로딩 화면 원본을 실제 이미지 참조로 첨부했습니다. 실제 애니메이션 영상이나 구현용 스프라이트가 아닌 동작 방향 제안입니다.

대화에 표시된 순서:

1. [책을 꼬옥 안기](book-hug.png) — 준비 → 꼬옥 → 끄덕. [전체 생성 프롬프트](book-hug.prompt.txt).
2. [꼬리 살랑, 고개 갸웃](tail-curiosity.png) — 살랑 → 쫑긋 → 갸웃. [전체 생성 프롬프트](tail-curiosity.prompt.txt).

두 시안 모두 1536×1024이며, 캐릭터의 주황색 털·크림색 얼굴·청록색 옷과 책, 종이 배경, 갈색 글자, 청록색 점을 유지했습니다. 사용자가 1번을 선택해 [책 안기 모션을 앱에 적용하고 자연스럽게 다듬었습니다](../startup-book-hug-v2/README.md).
