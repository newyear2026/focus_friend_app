# 현재 앱 디자인 확인

에뮬레이터에서 현재 설치된 개발 앱을 열어 직접 캡처했습니다. 화면 변경이나 소스 수정은 수행하지 않았습니다.

| 순서 | 화면 | 현재 상태 |
|---|---|---|
| 1 | 홈 | 남색 고양이 일러스트, 굵은 남색 제목, 초록 CTA, 25/50분, 오늘의 집중. 새 디자인 적용. |
| 2 | 집중 | 기존 CustomPainter 방과 주황 고양이. 타이머가 그림 아래에 있음. 정상 기록을 남기지 않는 1분 체험으로 촬영. |
| 3 | 기록 | 기존 베이지/회갈색, 누적 합계 카드와 기록 목록. 참고 이미지의 주간 그래프는 아직 없음. |
| 4 | 설정 | 하단 시트로 짧은 집중·체험·알림·소품 진입 제공. 참고 이미지의 별도 설정 화면과 소리·백업 기능은 아직 없음. |

전체 캡처 모음: `current-app-design.png`. 원본은 1080×2160이며 모음은 각 화면을 360×720으로 축소해 나란히 배치했습니다. 집중 화면의 체험 전용 문구는 일반 집중 문구와 다릅니다. 방·고양이·타이머 배치는 현재 앱이 공유하는 집중 화면입니다.

가장 눈에 띄는 차이는 홈에서 집중으로 이동할 때 방·고양이·색상·글꼴 스타일이 바뀌는 것입니다. 다음 디자인 수정은 집중 화면부터 홈의 일러스트와 타이포그래피를 공유하도록 하고, 이후 기록·설정을 맞추는 순서가 적합합니다.

1080×2160 화면에서 홈의 주요 조작과 하단 메뉴는 모두 보였습니다. 화면만으로 접근성 전체, 스크린리더 동작, 장기 타이머 동작을 검증한 것은 아닙니다. 이번 확인에서는 코드를 수정하거나 회귀 테스트를 다시 실행하지 않았습니다.

확인 후 체험을 닫고 홈으로 복귀했습니다. 정상 완료 5분·1회 기록과 화분 해금 상태를 유지했습니다.
