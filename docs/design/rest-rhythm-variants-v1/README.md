# 휴식 리듬 변형 검증

기준: `fix/desk-friend-rest-motion`의 `37cf920`. 결과 브랜치: `feat/rest-rhythm-variants`.

모든 캐릭터가 같은 주기를 반복하던 휴식 리듬에 미리 정한 3~4개 변형을 추가했습니다. 쉬는 시간과 눈 깜빡임만 바꾸며 무작위를 사용하지 않습니다. 각 변형의 잔 들기 → 마시기 → 내리기 셀과 노출 틱은 기준과 정확히 같습니다.

[영상 검토 화면](index.html) · [1분 리듬 타임라인](60-second-rhythm.png)

| 친구 | 변형 길이 | 슈퍼주기 | 깜빡임 횟수 | 최대 동일 셀 유지 | 변형마다 동일한 동작 구간 |
|---|---|---|---|---|---|
| 펭귄 | 86 / 90 / 92틱 (7.17 / 7.50 / 7.67초) | 268틱, 22.33초 | 0 / 0 / 0 | 60틱 | 32틱 |
| 해달 | 8 / 9 / 10 / 11초 | 456틱, 38초 | 0 / 1 / 2 / 2 | 58틱 | 40틱 |
| 다람쥐 | 18 / 19 / 20초 | 684틱, 57초 | 2 / 2 / 2 | 60틱 | 74틱 |
| 사막여우 | 18 / 19 / 20초 | 684틱, 57초 | 2 / 2 / 2 | 57틱 | 74틱 |

12fps이므로 60틱은 5초입니다. 모든 최대 유지는 변형 사이와 마지막 → 첫 변형 경계를 포함합니다.

펭귄은 깜빡임 원화가 없고 고정 동작이 32틱입니다. 원래 최소 길이 8초(96틱)에서는 동작 사이 쉬는 자세가 최소 64틱이 되어 60틱 제한과 양립할 수 없습니다. 사용자가 선택한 **펭귄만 7~7.7초로 허용하고 5초 유지 제한 지키기**를 적용했습니다. 새 그림이나 반복 동작을 끼워 넣지 않았습니다.

다람쥐·사막여우는 18초 이상에서 5초 유지 제한을 지키려면 깜빡임 2회가 필요해 횟수는 2회로 두고 위치와 동작 앞뒤의 쉼을 바꿨습니다.

## 범위와 재현

production 변경은 `lib/friend_motion_clock.dart` 한 파일입니다. 관련 테스트 3개와 지정 캡처 도구만 수정했고, `assets/`, `lib/friend_motion_scene.dart`, 랫서팬더 휴식 코드는 기준과 같습니다. [최종 범위 검사](scope-check.json)

```sh
flutter test
flutter analyze
flutter test tool/capture_all_friend_motions_test.dart --dart-define=ALL_MOTION_OUTPUT=docs/design/rest-rhythm-variants-v1/capture
python3 docs/design/rest-rhythm-variants-v1/create_evidence.py /tmp/deskmate-motion-37cf920-baseline
```

증거 생성 스크립트는 기준 브랜치에서 같은 도구로 만든 캡처 폴더를 인자로 받습니다. 기준 캡처를 변경하지 않습니다. PNG 전수 대조와 MP4 변환을 마친 중간 `capture/frames/`는 저장 용량을 줄이기 위해 제거했고, 메타데이터·수치·시퀀스 해시·주요 화면·영상은 보관했습니다. 재실행은 위 캡처 명령으로 프레임을 다시 생성한 뒤 진행합니다.

커밋은 로컬 브랜치에만 만들며 푸시는 하지 않습니다.
