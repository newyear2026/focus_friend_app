# 창가 찻잔 휴식 QA

2026-10-15. 기준은 `../fennec-squirrel-rest-concepts-v1/04-window-tea.png`입니다. 사막여우의 안경·큰 귀·사막 창가와 다람쥐의 도토리 모자·배낭·숲 창가, 창밖을 향한 시선, 두 손으로 찻잔을 들고 돌아오는 자세를 비교했습니다.

## 실제 화면과 동작

`*-morning/day/evening/night-app.png`는 실제 Flutter 앱을 390×844dp, DPR 2로 캡처한 780×1688px 이미지입니다. `*-sip-app.png`, `*-paused-app.png`에서 한 모금과 일시정지를 확인했습니다. 모든 캡처는 격리된 MemoryStore를 사용했습니다.

`*-window-tea.mp4`는 제작 중 보드를 움직인 영상이 아니라 실제 앱의 최종 Painter를 264프레임, 12fps, 22초로 렌더한 전체 반복입니다. `*-video-contact.jpg`는 영상에서 2초 간격으로 추출한 비교이며 마지막 검은 칸은 타일 패딩입니다.

## 발견 및 수정

- P2 얼굴과 팔을 사각형으로 나누면서 작화 경계가 드러남: 연결된 원화 전체를 사용하고 얼굴 아래를 점진적으로 혼합하도록 바꿨습니다. 눈·안경은 동시에 두 장 겹치지 않습니다.
- P2 찻잔을 올리는 순간 머리 크기도 바뀜: 정렬에 사용한 범위에서 찻잔을 제외하고 머리 위쪽으로 한정했습니다.
- P2 중간 전환에서 컵 두 개가 겹쳐 보임: 같은 컵 중심으로 연결된 팔과 원화를 부드럽게 맞춘 뒤 합성하도록 했습니다. 큰 겹친 윤곽을 줄인 최종 렌더를 다시 확인했습니다.
- P2 무한 재생 미리보기에서 기존 테스트가 끝나지 않음: `pumpAndSettle` 대신 저장·화면 전환을 여러 프레임에 걸쳐 확인하도록 테스트를 수정했습니다. 취소·저장 실패·재시도·책상 복귀와 네 언어 큰 글자를 다시 검증했습니다.

## 남은 작은 차이

P3: 원화마다 몸통·꼬리·컵 모양에 작은 차이가 있고 일부 중간 전환은 부드러운 혼합 흔적이 남습니다. 완전히 같은 몸통 픽셀을 유지하는 방식은 아닙니다. 승인 시안과 닫힌 책의 표지 세부 무늬도 조금 다릅니다. 방·책 위치 고정, 단일 찻잔의 상승·한 모금·복귀 의미와 전체 반복은 유지됩니다.
