# 랫서팬더 연속 모션 검증

## 변경 범위

선택한 `../character-concepts/redpanda-writing-study.png`의 랫서팬더와 기존 `assets/images/redpanda-study-sheet.png`를 유지하고, 런타임 모션만 다듬었습니다. 새 이미지 생성이나 자산 픽셀 편집은 하지 않았습니다.

- 기존 0.8초 간격 필기 포즈 교체를 연속 메시 움직임으로 바꿨습니다. 손목이 작은 필기 스트로크를 만들고 4초 문장 리듬마다 잠시 쉽니다.
- 고개, 호흡, 꼬리는 서로 다른 작은 진폭과 느린 주기로 움직입니다. 노트의 바깥 모서리와 아래 표지는 책상에 고정합니다.
- 24초 루틴은 필기 → 연필을 내려놓고 내용 확인 → 페이지 들기/넘기기 → 다시 필기입니다. 얼굴·꼬리는 동일 그림을 유지하고 손·연필·노트 영역만 원래 포즈 사이를 전환합니다.
- 일시정지와 백그라운드 진입 때 현재 자세와 동작 시각을 보존합니다. 재개 후 그대로 이어지고, 24초 반복 경계에서 첫 시작 포즈로 돌아가지 않습니다.
- 타이머 엔진, 영구 저장, 보상, 시간대 배경은 변경하지 않았습니다. 동작 줄이기는 정지된 필기 포즈를 사용합니다.

## 시각 검증

`study-motion-preview.mp4`는 실제 production painter를 480×540px, 24fps, 576프레임으로 렌더링한 정확히 24초의 미리보기입니다. 네이티브 앱 녹화와 구분합니다. `character-motion-closeup.mp4`는 같은 영상의 캐릭터 영역을 확대했습니다. 재현: `flutter test tool/render_study_motion.dart` → `/tmp/focus-motion-frames/`.

`pose-contact.jpg`에서 시작, 필기 스트로크, 쉼, 확인, 페이지 전환, 반복 직전 상태를 나란히 검사했습니다. 초안에서 발견한 얼굴 겹침과 얼굴을 가르는 마스크 경계를 수정했습니다. 얼굴 아래 윤곽에 맞춘 영역 분리로 눈·코·입을 한 그림으로 유지하고, 페이지 전환은 짧은 smoothstep 보간으로 연결합니다. 불투명 부분은 독립 레이어 가산 합성으로 유지합니다.

필기·호흡은 연속 변형입니다. 페이지는 기존 그림 사이의 짧은 전환이므로, 한 장이 완전히 회전하는 물리 기반 페이지 애니메이션은 아닙니다. 실제 홈 크기에서 움직임은 집중을 방해하지 않도록 작게 설정했습니다.

## 자동 검증

- `flutter test`: 37개 통과 (`tests.log`). 노트 고정점, 60Hz 샘플 간 이동 연속성, 24초 루프, 프레임 누락을 포함한 긴 시간 경과, 일시정지/재개, 동작 줄이기, 포즈 전환 중 얼굴 유지와 불투명도, 기존 앱/저장/보상 테스트 포함.
- `flutter analyze`: No issues found (`analyze.log`).
- `flutter build apk --debug`: 성공. APK를 별도 파일에 고정하고 일반 개발 앱을 `adb install --no-streaming -r`로 업데이트했습니다.

## Android 확인

Android 16 / emulator-5554 (1080×2160px)의 일반 개발 앱에서 기록 없는 1분 체험을 실행했습니다. 필기, 일시정지, 재개, 체험 완료, 확인 후 홈 복귀를 확인했습니다. 종료 확인을 누르는 동안 체험의 종료 시각에 도달하여 정상 완료가 우선 적용됐으며, 완료 화면의 확인을 눌러 마무리했습니다.

- `writing-demo-start.png`: 실제 체험의 필기 장면.
- `paused-native-a.png` / `paused-native-b.png`: 1초 이상 간격으로 찍은 정지 화면. 캐릭터 영역 (300,600–670,900)의 픽셀이 정확히 같았습니다.
- `final-home-native.png`: 체험 확인 후 홈으로 복귀.
- `data-preservation.json`: 업데이트 전과 체험 종료 후 history(3개), completedMs, completedCount, unlocks 전체 값이 같으며 active=null입니다.
- `writing-demo-native.mp4`: 네이티브 녹화 원본. 26초 녹화를 요청했지만 에뮬레이터가 4.53초/12프레임만 저장했습니다. 전체 동작이나 성능을 입증하는 자료로 쓰지 않으며, 사용자에게 보여주는 24초 영상은 별도의 production painter 렌더임을 구분합니다. 실기기의 프레임 성능은 별도 확인 대상입니다.

시각 비교에서 얼굴 겹침과 마스크 경계 문제를 해결했습니다. 글꼴·색·홈 배치·시간대 전환은 이번 모션 변경에서 유지했습니다. 같은 작업공간의 다른 UI 변경도 되돌리지 않았습니다.
