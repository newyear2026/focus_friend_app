# 선택형 보상 광고 흐름 시안

2026-10-27. 기존 Deskmate의 사막여우 방·친구 미리보기·집중 화면을 참조한 UI 이미지 제안입니다. 앱 코드·결제·광고 SDK는 변경하지 않았습니다.

[최종 이미지](rewarded-ad-flow.png) · [전체 생성·수정 프롬프트](prompts.json)

1. **친구 선택:** 집중/휴식 모습을 확인한 뒤 ‘광고 보고 25분 체험’ 또는 구매를 선택합니다. 최종 시안의 왼쪽은 휴식 미리보기입니다.
2. **시청 전 안내:** 광고 1회 시청 완료의 보상은 다음 25분 집중 1회 체험입니다. ‘다음에’와 닫기를 제공합니다. 실제 광고 영상은 광고 제공사가 공급하며 이 시안에 포함하지 않았습니다.
3. **체험 준비:** 보상 수령 후 책상으로 돌아옵니다. 사용자가 ‘집중 시작’을 눌러야 타이머가 시작됩니다. 진행 중인 집중 화면에는 광고를 표시하지 않습니다.

4,900원은 BM 논의의 가격 실험 예시입니다. 시청 중 닫기·광고 로딩 실패·보상 재전달·구매 복원은 구현 단계에서 별도 상태로 다뤄야 합니다. 현재 무료 제공된 친구의 이용 권한 변경을 뜻하지 않습니다.

생성 모드: built-in ImageGen. 기본 흐름 보드 생성 후 왼쪽 집중/휴식 선택 표시 한 곳을 수정했습니다. 원본 결과는 Codex generated_images에 남기고 최종본만 프로젝트 폴더로 복사했습니다.
