타이머·캐릭터·일시정지·종료 조작을 유지하고, 조작 영역 아래 여백을 두어 하단 배너를 분리합니다. 집중과 휴식에서는 같은 위치에 하나만 표시하고, 광고 제거 구매자는 배너를 숨기는 제안입니다. 광고 문구·아이콘·색상은 가상의 예시이며 실제 소재와 배너 크기는 SDK와 기기에 따라 달라집니다.

이미지 생성 시안으로, 실제 Flutter 캡처나 구현 결과가 아닙니다. 앱 코드·광고 SDK·AdMob 설정·결제 동작은 변경하지 않았습니다. 자동 갱신과 노출 조건은 정적 이미지로 검증되지 않으며 구현 시 별도로 확인해야 합니다.
