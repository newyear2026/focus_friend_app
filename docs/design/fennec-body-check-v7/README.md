# 사막여우 몸통 흔들림 재확인

현재 사막여우만 실제 `FocusFriendApp` 위젯으로 한 주기(22초)를 새로 캡처했습니다. 몸통 흔들림은 여전히 남아 있습니다.

1. **진입 — 문제 있음.** 8.5~9초, 10→17→18→16번 그림으로 바뀌며 등선·어깨·몸통과 꼬리 형태가 함께 변합니다.
2. **한 모금 유지 — 고정 정상.** 9~10.5초는 같은 그림을 유지합니다. 이 구간의 새 캡처 18프레임은 픽셀이 같습니다.
3. **복귀 — 문제 있음.** 10.5~11초, 같은 원화를 역순으로 지나며 몸 형태 변화가 다시 드러납니다.

몸 전체를 시간에 따라 이동·회전시키는 효과는 없습니다. 연결 원화 자체의 신체 형태가 달라, 컵과 팔을 움직이는 중 몸도 움찔하는 것처럼 보입니다. 다음 보완은 몸통과 꼬리 외곽을 같은 기준에 맞추면서 눈·팔·컵이 바뀌는 원화를 수정하는 것입니다.

이번 작업은 재확인입니다. 사막여우 원화와 앱 모션 코드는 변경하지 않았습니다. 캡처 도구에 캐릭터 하나를 선택할 수 있는 옵션만 추가했습니다.

[원래 속도 5초 영상](fennec-body-1x.mp4)은 한 주기의 7.5~12.5초 구간입니다. 사용자 저장 상태 대신 메모리의 휴식 세션으로 렌더링했습니다. 실제 기기 화면 녹화나 GPU 성능 검사는 아닙니다.
