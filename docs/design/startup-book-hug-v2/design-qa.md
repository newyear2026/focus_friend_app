## 이전 문제와 수정

| 문제 | 수정 및 확인 |
| --- | --- |
| P2: 고개를 숙이면 머리 높이가 줄어 눌리는 인상 | 목을 기준으로 작게 회전하도록 변경. 전 주기의 머리 기준점 간 거리 유지 검증과 전후 포즈 비교를 통과했습니다. |
| P2: 감은 눈 모양이 끄덕임 중 갑자기 교체됨 | 하나의 편안한 감은 눈 표정 유지. 시안의 중간 웃는 눈은 자연스러운 연결을 위해 의도적으로 조정했습니다. |
| P2: 책과 팔의 전체 이동으로 어깨가 미끄러짐 | 어깨를 고정하고 팔꿈치·손으로 갈수록 책을 따라가도록 변경. 책은 단일 회전·이동만 적용해 크기와 모서리를 유지합니다. |
| P2: 안기·멈춤·끄덕임이 분리되어 보임 | 동작 시간을 겹치고 방향 전환 시 속도·가속도가 부드럽게 이어지도록 보간. 20ms 간격 위치 변화와 루프 연결을 확인했습니다. |

수정 후 540프레임 연속 캡처와 위 비교를 다시 확인했습니다. 관찰한 P0/P1/P2 문제는 해결됐습니다. 동작의 빠르기·강도에 대한 추가 선호 조정은 가능합니다.
