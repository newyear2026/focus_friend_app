# 사막여우 · 다람쥐 휴식 모션 시안 3종

기존 앱 캐릭터와 방을 참고한 정지 핵심 자세 시안입니다. 각 이미지의 위쪽 행은 사막여우, 아래쪽 행은 다람쥐이며 왼쪽에서 오른쪽으로 동작을 읽습니다. 이 시안 제작으로 앱의 실제 모션을 변경하지는 않았습니다.

1. [따뜻한 차 한 모금](01-tea.png): 잔 들기 → 한 모금 → 내려놓기. 기본 휴식 동작 추천.
2. [작은 기지개](02-stretch.png): 팔 올리기 → 쭉 기지개 → 편안한 자세. 귀와 꼬리로 캐릭터 개성을 살리는 방향.
3. [창밖 보며 쉬기](03-window.png): 고개 돌리기 → 창밖 바라보기 → 돌아오기. 오래 켜 두는 잔잔한 휴식 방향.

제작 도구는 built-in ImageGen이며, 기존 이미지를 정체성과 화풍의 참고로 사용한 새 컨셉 보드 생성입니다. 원본 생성 파일과 참고 경로는 [manifest.json](manifest.json)에 있습니다. 최종 프롬프트는 [차 마시기](01-tea.prompt.txt), [기지개](02-stretch.prompt.txt), [창밖 보기](03-window.prompt.txt)에 보관했습니다. 생성된 그림을 그대로 복사했으며 별도 픽셀 편집을 하지 않았습니다.

실제 애니메이션 제작 시에는 이 시안을 원화 방향으로 사용하고, 배경·공책·컵의 고정 좌표와 캐릭터 크기를 다시 맞춰야 합니다. 그림 3장은 핵심 자세를 설명하며 최종 재생 프레임이나 자연스러운 반복 자체를 검증한 결과는 아닙니다.

## 조합 시안: 창밖 보며 차 한 잔

사용자의 제안에 따라 ①과 ③을 합친 [새 시안](04-window-tea.png)을 추가했습니다. 두 손으로 잔을 감싸고 풍경을 바라보기 → 창가로 고개를 향한 채 한 모금 → 잔을 가슴 아래로 내려 편안하게 쉬기의 흐름입니다. 사막여우는 사막 노을, 다람쥐는 숲을 바라봅니다.

실제 제작에서는 잔을 감싼 기본 자세로 돌아온 뒤 충분히 머무는 20~24초 반복을 제안합니다. 위쪽 사막여우·아래쪽 다람쥐의 정지 핵심 자세 시안이며 앱 모션 적용은 하지 않았습니다. built-in ImageGen에 기존 차·창밖 보기 보드를 참고로 전달해 새로 생성했고 픽셀 편집 없이 복사했습니다. 최종 요청문은 [04-window-tea.prompt.txt](04-window-tea.prompt.txt)입니다.
