- **배치:** 원본과 같은 390×642.68 dp에서 비교했고 실제 휴대폰 비율 390×844 dp도 캡처했습니다. 이미지 비율을 유지하며 글자·로딩 점과 겹치지 않습니다. UI를 통째로 이미지로 넣지 않았습니다.

- **이미지:** 선택 이미지에서 built-in Image Gen으로 따로 생성한 종이 배경과 투명 캐릭터 PNG를 사용합니다. 캐릭터는 1254×1254 RGBA이며 배경 박스나 잘린 귀·꼬리·책이 없습니다. 재생성된 일부 눈·윤곽·종이 질감 차이는 P3이며 원본과 완전 동일한 픽셀이라고 주장하지 않습니다.
- **문구·상태:** 원래 한국어 안내를 유지합니다. 저장소 오류에서는 같은 화면의 청록색 재시도 버튼을 표시하고 준비가 끝나면 홈으로 넘어갑니다. 로딩 점은 1.8초 주기로 부드럽게 밝아지며, 동작 줄이기·백그라운드·TickerMode에서는 정지합니다.
