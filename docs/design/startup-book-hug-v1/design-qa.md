## 발견한 문제와 수정 이력

1. **P2 — 책 표지 변형:** 최초 전체 이미지 변형에서 책 아래 금색 선이 휘었습니다. [수정 전](initial/warped-book.png). 책·양팔·발을 분리하고 책을 통째로 이동·균일 축소하도록 수정했습니다. 최종 [포즈 비교](pose-comparison.png)에서 표지 테두리와 새싹 문양이 유지됩니다.
2. **P2 — 진한 바닥 그림자:** 분리된 몸통 자산의 그림자가 단단한 갈색 타원으로 보였습니다. [수정 전](initial/hard-shadow.png). 원본처럼 낮은 알파와 부드러운 경계로 재생성했습니다. 최종 전체 화면에서 바닥과 자연스럽게 연결됩니다.
3. **픽셀 회귀 — 투명 여백과 발:** 책 자산의 거의 투명한 외곽 픽셀이 이동하고, 발 내부의 알파 252–253 때문에 뒤의 책 색이 미세하게 비쳤습니다. 책의 실제 그림 바깥을 클립하고 발 내부 불투명도를 보정했습니다. 최종 픽셀 테스트에서 발·꼬리·바닥의 지정 영역이 준비·안기·끄덕임 사이에 동일합니다.

수정 후 연속 캡처와 동일 조건 비교를 다시 실행했습니다. 남은 P0/P1/P2 문제는 관찰되지 않았습니다.
