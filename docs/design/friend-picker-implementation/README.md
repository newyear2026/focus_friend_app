# 하단 친구 탭 구현

사용자가 선택한 `../character-menu-location-concepts-v1/bottom-friend-tab.png`의 **책상 · 친구 · 기록 · 설정** 배치를 기존 Flutter 앱에 적용했습니다.

- 친구 선택 → 방 미리보기 → 적용 → 책상 복귀. 미리보기 취소는 저장하지 않습니다.
- 기존 랫서팬더와 새 펭귄·해달·다람쥐·사막여우의 다섯 친구를 고를 수 있습니다.
- 선택한 친구는 기존 원자적 저장 방식으로 보관하고, 옛 저장 파일은 랫서팬더를 기본값으로 사용합니다.
- 후속 작업으로 **펭귄·해달은 필기·페이지 넘김·찻잔 휴식 애니메이션**을 지원합니다. 다람쥐·사막여우도 [창가 찻잔 휴식](../fennec-squirrel-window-tea-v1/README.md)을 지원하며, 두 친구의 집중 장면은 정지 일러스트입니다. [펭귄·해달 모션 제작 기록](../penguin-otter-motion-v1/README.md). 랫서팬더의 기존 애니메이션과 현지 시간에 따른 방 조명은 유지합니다.
- 진행 중인 세션이 있을 때는 기존처럼 하단 메뉴를 숨깁니다. Android 설치 확인 시에도 기존 일시정지 세션을 종료하거나 변경하지 않았습니다.
- 실제 결제, 판매 권한, 상품 잠금은 구현하지 않았습니다.

`flow-overview.jpg`는 실제 Flutter 캡처를 이어 붙인 사용 흐름입니다. 화면 속 버튼·글자·타이머는 네이티브 Flutter UI입니다. 새 배경의 UI 제거에는 built-in ImageGen을 사용했으며, 생성 프롬프트·원본 경로는 각 `*.prompt.txt`에 있습니다. 실행용 자산은 `assets/images/friends/`에 있습니다.

검증 내용과 비교: [design-qa.md](design-qa.md).
