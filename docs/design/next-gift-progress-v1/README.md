# 다음 선물 진행도 v1 (2026-11-19)

경쟁 앱 비교 제안 1(`../competitive-gaps-v1/01.png`)의 첫 단계. 기존 소품 3종 규칙은 그대로 두고, 다음 소품까지 남은 시간을 보여준다.

- 홈 대기: `오늘의 집중` 아래 `따뜻한 머그컵까지 35분` + 진행 막대. 첫 완료 전에는 `첫 집중을 마치면 작은 화분`(막대 없음).
- 집중 완료: 확인 버튼 위 같은 줄. 1분 체험·휴식 완료에는 표시하지 않음.
- 모은 소품: 잠긴 소품 카드에 `25/60분` 진행 막대.
- 모든 소품을 받으면 줄이 사라짐. 진행도는 평생 정상 완료 시간(`completedMs`) 기준이며 저장 형식 변경 없음.
- 큰 글자(1.2배 초과)에서는 짧은 이름(`머그컵까지 35분`)으로 잘림 방지.

캡처: `flutter test --no-pub tool/capture_next_gift_test.dart` (메모리 저장소, 실제 아트)
