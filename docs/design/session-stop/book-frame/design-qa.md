# 책장·책갈피 종료 패널 검증

final result: passed

대상은 사용자가 첨부해 선택한 `selected.png`의 책장 테두리와 청록 책갈피입니다.
원본과 실제 Flutter 화면은 모두 853×1844px입니다
(426.5×922 logical pixels, devicePixelRatio 2). 전체 비교는 `comparison.png`,
종료 패널 확대 비교는 `detail-comparison.png`에서 나란히 확인했습니다.
초기 비교도 `comparison-initial.png`와 `detail-comparison-initial.png`로 보관했습니다.

첫 비교에서 발견하고 수정한 항목:

- P2 해결: 큰 글자에서는 책갈피 끝과 초상의 귀가 가까웠습니다. 초상을 64로
  줄이고 위 여백을 76으로 확보하여 책갈피와 겹치지 않도록 했습니다.
- P2 해결: 가로 화면에서 종료 버튼이 아래 프레임에 일부 가려졌습니다. 짧은
  화면에서는 초상을 64, 위 여백을 30으로 줄여 두 버튼을 모두 보이게 했습니다.

원화는 기본 Image Gen으로 생성한 투명 PNG이고, 원본 생성 파일을 수정하지 않고
프로젝트에 복사했습니다. `asset-prompt.txt`와 `asset-metadata.json`이 생성 및
분할 확대 근거입니다. 아홉 영역 확대의 모서리·책갈피·접힌 종이는 고정하고
중앙과 직선 가장자리만 화면에 맞게 늘립니다.

## 최종 화면 비교

모두 저녁, 25분 집중, 잔여 24:30 상태를 주입한 실제 Flutter 위젯 캡처입니다.
Android 기기나 OS의 화면 캡처는 아닙니다.

- `sheet.png`: 기본 390×844 logical pixels, 780×1688px.
- `sheet-reference-size.png`: 선택 원본과 같은 853×1844px.
- `sheet-compact-large-text.png`: 작은 360×740 화면, 글자 1.6배, 720×1480px.
- `sheet-landscape.png`: 가로 740×360 화면, 1480×720px.

기본·원본 크기 화면에서 책장 테두리의 연속성, 책갈피의 잎 장식, 오른쪽 종이
접힘, 초상과 제목의 가로 배치 및 두 버튼을 확인했습니다. 큰 글자 화면에서는
책갈피·귀·제목·본문이 겹치지 않고 두 버튼이 보입니다. 가로 화면에서도 두 버튼이
프레임 안에 완전히 보이며 조작할 수 있습니다. 더 긴 번역은 내부 스크롤로
접근합니다. 테두리 이미지는 터치를 가로채지 않습니다.

- 글꼴과 위계: 기존 Pretendard, 제목 24/800, 본문 14/500, 보조 14,
  계속하기 23/800, 종료하기 20/800을 사용합니다. 제목은 한국어에서 두 줄입니다.
- 간격: 좌우 콘텐츠 여백 28, 기본 위 여백 44, 아래 여백 26입니다. 프레임
  바깥에는 좌우 4, 아래 12의 안전 여백을 둡니다. 최소 버튼 높이는 각각 56/48입니다.
- 색: 앱의 `deskPaper` #292630, `deskInk` #FFEBC5, `deskMuted` #C5B8BA,
  `deskAccent` #FFC16F와 검정 반투명 배경을 유지했습니다.
- 이미지: 랫서팬더는 기존 `companion-portrait.png`를 비율 유지하여 표시합니다.
  책장 프레임은 투명 PNG 1340×1174px를 그대로 사용합니다. 시안의 방과 현재
  앱 배경 자세가 약간 다른 점은 패널 범위와 구분했습니다.
- 문구와 조작: 계속하기·바깥 터치·아래로 밀기·뒤로 가기는 현재 집중을
  유지합니다. 종료하기만 중도 종료로 기록합니다. 해금 누적에서 제외한다는
  안내와 체험·휴식의 별도 기록 안내도 유지합니다.
