# 집중 종료 하단 패널 검증

> 후속으로 선택한 책장·책갈피 테두리는 [book-frame/design-qa.md](book-frame/design-qa.md)에 검증했습니다. 아래 내용은 기본 하단 패널의 구현 이력입니다.

final result: passed

선택 시안 `selected-sheet.png`와 첫 Flutter 구현을 같은 977×1610px
(488.5×805 logical pixels, devicePixelRatio 2)로 캡처하여
`sheet-comparison-initial.png`, `sheet-detail-comparison-initial.png`에서 함께 비교했습니다.
검증 범위는 종료 패널이며, 방과 기존 타이머 배치는 현재 앱을 사용합니다.

## 첫 비교에서 수정할 항목

- P2 — 제목 줄바꿈: 넓은 화면에서는 한 줄, 기본 화면에서는 마지막 ‘요?’만
  다음 줄로 떨어졌습니다. 언어별 제목 줄바꿈을 지정하고, 큰 글자에서는
  초상 크기를 줄여 제목 폭을 확보합니다.
- P3 — 종료 버튼 글자가 시안보다 작습니다. 18에서 20 logical pixels로 맞춥니다.

## 최종 재비교

`sheet-comparison.png`와 `sheet-detail-comparison.png`에서 선택 시안과 수정 후
구현을 함께 열어 전체 구성과 패널 상세를 재확인했습니다. 기본 휴대폰
390×844 logical pixels / 780×1688px는 `sheet.png`, 작은 화면과 글자 1.6배
360×740 logical pixels / 720×1480px는 `sheet-compact-large-text.png`입니다.
모두 같은 25분 집중·잔여 24:30·저녁 상태를 주입한 실제 Flutter 위젯 캡처입니다.
Android OS 화면을 캡처한 것은 아닙니다.

- 글꼴·위계: 앱의 Pretendard를 사용합니다. 제목은 언어별 두 줄로 정리해
  처음 발견한 P2를 해결했습니다. 제목 24/800, 본문 15/500, 보조 문구 14,
  계속하기 23/800, 종료하기 20/800입니다. 큰 글자에서는 초상을 72로 줄여
  제목 폭을 확보하고 긴 패널은 스크롤할 수 있습니다.
- 간격·배치: 전체 폭 하단 패널, 상단 모서리 28, 손잡이 44×5, 좌우 여백 24,
  초상과 제목의 가로 배치, 두 문구, 큰 주황색 버튼과 보조 종료 버튼을 확인했습니다.
  기본 화면과 확대 글자 화면에서 글자 겹침이나 버튼 잘림이 없습니다.
- 색·대비: 기존 `deskPaper` #292630, `deskInk` #FFEBC5, `deskMuted` #C5B8BA,
  `deskAccent` #FFC16F를 사용합니다. 배경은 반투명 검정으로 구분합니다.
  모형의 미세한 조명·버튼 그라데이션 대신 기존 앱의 단색 표면을 사용한 것은
  P3 범위의 의도된 차이입니다.
- 원화·이미지: 작은 랫서팬더는 기존 투명 `companion-portrait.png` 원본입니다.
  책·앞발·귀를 자르지 않고 종횡비를 유지합니다. 배경 캐릭터는 앱의 실제 필기
  원화와 현재 배치를 사용하므로 생성 시안 속 배경 자세와 다릅니다. 변경 대상인
  종료 패널의 원화·배치 비교와 별도로 구분했습니다.
- 문구·조작: ‘계속하기’는 확인 창만 닫습니다. ‘종료하기’만 기존 엔진의
  같은 세션 ID로 중도 종료합니다. 바깥 터치·아래로 밀기·뒤로 가기는 종료를
  확정하지 않습니다. 체험·휴식에는 해당 모드의 기록 안내만 표시합니다.

## 검증과 남은 차이

- `flutter analyze --no-pub`: 문제 없음.
- 전체 `flutter test --no-pub`: 70개 통과.
- `flutter build apk --debug --no-pub`: 성공. `build/app/outputs/flutter-apk/app-debug.apk`.
- 새 패널 검증 10개: 계속하기, 실제 종료 시간과 보상 제외, 취소 제스처,
  팝업 중 종료 시각 도달 시 중복 기록 방지, 체험·휴식 분리, 네 언어와 큰 글자.
- 캡처 검증 3개: 기본 화면, 원본과 같은 뷰포트, 작은 화면·큰 글자.
- 남은 P3: 이미지 모형의 미세한 글꼴 모양·표면 조명 차이. 미해결 P0/P1/P2 없음.

다시 캡처하려면 `flutter test --no-pub tool/capture_stop_sheet_test.dart`를 실행합니다.
캡처와 동작 테스트는 메모리 저장소를 사용하므로 일반 앱 데이터는 변경하지 않습니다.
