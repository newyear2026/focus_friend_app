# 랫서팬더 2D 컷아웃 애니메이션

## 요청과 구현

이전 전체 그림의 메시 변형·포즈 겹침 영상을 사용자가 거부했습니다. 머리, 눈, 몸통, 윗팔, 앞팔/손, 꼬리, 노트를 독립적으로 그리는 2D 컷아웃 리그로 교체했습니다. Flutter Canvas에서 원화를 관절 주위로 회전·이동하며, 전체 캐릭터 이미지의 변형과 크로스페이드는 제거했습니다. Rive/Spine 파일을 생성한 것은 아닙니다.

- `lib/study_motion.dart`: 두 뼈 IK, 필기 경로와 24초 키프레임 타임라인. 팔 길이는 고정되고 손과 연필의 결합점은 일치합니다.
- `lib/study_puppet.dart`: 원화 레이어 조립, 눈꺼풀과 눈동자, 필기 획, 페이지의 회전과 휘어짐. 각 원화는 불투명하게 한 번 배치하며 팔 연결부만 겹쳐 조립합니다.
- `lib/study_scene.dart`: 기존 홈 애니메이션 시계와 새 리그 연결. 일시정지·재개·백그라운드·동작 줄이기 처리를 유지합니다.
- 원화: [redpanda-puppet-parts.png](../../../assets/images/redpanda-puppet-parts.png), 1774×887 RGBA. built-in image_gen으로 생성했습니다. 기존 랫서팬더를 정체성 참고로 사용하고 분리 원화를 새로 그렸습니다. [전체 생성 프롬프트](../../../assets/images/redpanda-puppet-parts.prompt.txt).

## 동작

필기할 때 눈동자가 연필 쪽을 보고, 손·연필 끝·노트에 나타나는 글씨가 같은 경로를 따릅니다. 낱말 사이에는 펜을 들고 줄을 바꿀 때는 충분한 시간을 둡니다. 이후 내용을 확인하고 오른손으로 오른쪽 페이지를 잡아 왼쪽으로 넘긴 뒤 다시 필기합니다. 눈 깜빡임, 작은 고개 움직임, 꼬리의 회전과 호흡은 별도 제어합니다.

## 렌더링 검증

`character-animation.mp4`는 실제 앱 painter를 사용한 24fps/24초/512×440px 캐릭터 단독 미리보기입니다. 네이티브 녹화와 구분합니다. 재현: `flutter test tool/render_study_motion.dart --dart-define=PUPPET_ONLY=true`. 전체 홈 배경 포함 렌더는 같은 명령에서 PUPPET_ONLY를 빼면 됩니다.

초기 리그 검토에서 직선으로 잘린 눈 깜빡임, 팔 연결부의 노출, 노트 가장자리에서 손과 연필의 분리, 너무 빠른 줄바꿈을 발견했습니다. 곡선 눈꺼풀, 관절 연결부 겹침, 손의 도달 범위와 줄바꿈 시간 조정으로 해결했습니다. 시선은 두 눈동자가 같은 연필/페이지 위치를 보도록 연결했습니다. 그림의 차이는 새 분리 원화를 사용한 결과이며 얼굴을 섞어 표현하지 않습니다.

## 검증

- 전체 테스트 37개 통과 (`tests.log`). 120Hz로 한 주기를 샘플링하여 뼈 길이, 연필 결합점, 실제 필기 경로, 줄바꿈과 반복 경계를 확인합니다. 기존 같은 홈 유지, 일시정지·재개, 동작 줄이기, 저장·보상·목표·사운드 테스트 포함.
- `flutter analyze`: No issues found (`analyze.log`).
- Android 개발 APK 빌드 성공.

Android 16 / emulator-5554의 일반 개발 앱을 기록 보존 업데이트한 뒤, 기록 없는 1분 체험으로 필기 → 일시정지 → 재개 → 종료 → 홈 복귀를 확인했습니다. `native-writing.png`, `native-paused-a.png`, `native-paused-b.png`, `native-home.png`가 실제 화면입니다.

- 일시정지 전후 1초 이상 간격의 캐릭터 영역 (300,580–720,920) 픽셀이 동일했습니다.
- 업데이트 전과 체험 종료 후 기록 4개, 완료 누적, 보상 전체가 같고 active=null입니다 (`data-preservation.json`).
- `native-writing.mp4`는 540×1080px 실제 녹화입니다. 12초를 요청했고 에뮬레이터가 8.51초/120프레임으로 저장했습니다. 이 환경의 녹화로 실기기 프레임 성능을 보장하지 않습니다.
- 전체 동작의 시각 검토는 576프레임의 정확한 24초 production painter 렌더와 `character-contact.jpg`를 사용했습니다. 이는 네이티브 녹화와 구분합니다.

현재 원화는 동일한 랫서팬더의 분리 원화로 새로 제작되어 이전 포즈 시트와 세부 모양이 다릅니다. 관절 기반 2D 컷아웃이므로 전통적인 손그림 프레임 애니메이션이나 외부 Rive/Spine 편집 파일은 아닙니다. 페이지는 프로그램으로 그리는 종이 레이어입니다. 기존 저장·타이머 규칙 및 병행 UI 변경은 보존했습니다.
