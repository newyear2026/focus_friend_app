# 캐릭터 속도와 전체 흔들림 수정

## 원인과 변경

- 기존 필기 12장은 1초마다 반복됐고 전체 동작은 약 9.33초였다. 프레임 전체를 교체하면서 얼굴·귀·꼬리까지 원본 그림의 미세한 차이를 따라 변했다.
- 시트 안의 책 밑변 기준점도 첫 필기 프레임보다 위로 4px, 아래로 8px까지 달랐다. 렌더러에 프레임별 기준점을 등록해 위치를 맞췄다.
- 원본 PNG는 변경하지 않았다. 기존 첫 프레임을 고정 바탕으로 사용하고 필기 손·연필, 생각하는 손, 페이지와 팔이 겹치는 부분만 로컬 영역으로 합성한다. 눈과 캐릭터의 원래 그림을 재생성하지 않는다.
- 필기 12장은 이제 2초 동안 재생되고 매번 0.5초간 멈춘다. 전체는 필기 7.5초 → 생각 4초 → 필기 7.5초 → 페이지 넘김 2초 + 멈춤 1초, 총 22초다.
- 타이머 시간과 모션 시간은 분리하며 기존 일시정지·재개·백그라운드·동작 줄이기 규칙을 유지한다.

## 검증

- `flutter analyze`: 문제 없음.
- `flutter test`: 41개 통과. 추가한 렌더링 회귀 검사에서 36개 원본 자세 모두 고정된 상단 얼굴·귀와 꼬리 영역의 픽셀 변화가 0임을 확인했다.
- 확대된 실제 렌더링으로 손·연필·종이의 겹침 경계를 확인했다. 합성은 기존 그림의 부분 교체이므로 손 주변 질감의 작은 변화는 남을 수 있다.
- Android 검증 명령: `FOCUS_MOTION_EVIDENCE_DIR=docs/design/calm-study-motion python3 tool/verify_study_animation.py`. 별도 임시 소스 복사본과 메모리 저장소를 사용한다.
- Android 통합 테스트 통과. 촬영한 [수정된 실행 영상](native-animation.mp4)에서 필기·생각·페이지 넘김을 확인했다. 두 일시정지 화면은 2초 간격으로 픽셀이 동일하며 재개 후 다음 주기로 이어진다. 테스트용 타이머는 고정 시각이므로 영상 속 남은 시간은 25:00을 유지한다.
- 검증한 소스와 작업 폴더 소스가 일치하는 것을 확인한 뒤 일반 개발 앱을 업데이트했다. 설치 전후 SQLite 상태 본문이 동일하고 기존 기록 6개가 유지됐다. [저장 상태 검증](data-preservation.json).

이전 속도/렌더러 기록은 `../app-cel-motion/`에 보존했다.
