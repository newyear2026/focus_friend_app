## 랫서팬더와 같은 시간 기준

현재 앱의 lib/room_ambience.dart를 확인했습니다. 휴대폰 현지 시간 기준입니다.

| 단계 | 시간 | 시안의 조명 방향 |
| --- | --- | --- |
| 아침 | 05:30–07:59 | 부드러운 아침 햇살과 차가운 그림자 |
| 낮 | 08:00–17:29 | 밝고 자연스러운 주광 |
| 저녁 | 17:30–19:59 | 주황·보랏빛 노을과 따뜻한 실내 조명 |
| 밤 | 20:00–다음 날 05:29 | 짙은 남색 하늘, 달·별, 국소적인 스탠드 빛 |

밤은 저녁 노을을 남기지 않고, 창밖은 푸르게 어두워지며 얼굴과 노트는 따뜻한 빛으로 읽히는 방향입니다. 각 친구의 설경·바다·숲·사막과 오아시스를 유지했습니다.

## 실제 첨부한 이미지

각 호출에 다음 세 이미지를 직접 첨부했습니다.

1. 해당 친구의 현재 앱 장면: ../../../assets/images/friends/{캐릭터}-scene.png
2. 해당 친구의 기존 3단계 시안: ../friend-time-of-day-concepts-v1/{캐릭터}.png
3. 랫서팬더의 실제 밤 배경: ../../../assets/images/immersive/room-night.png

랫서팬더 밤 이미지는 조명 참고이며 다른 친구의 방 구조나 풍경을 교체하기 위한 자료로 사용하지 않았습니다. 랫서팬더의 아침·낮·저녁·밤 실제 배경 네 장을 직접 확인한 뒤 시간대 차이를 프롬프트에 반영했습니다. 상세 입력 및 생성 파일 경로는 manifest.json에 있습니다.

## 확인 및 적용 상태

네 생성 결과를 직접 확인했습니다. 모두 아침·낮·저녁·밤 네 라벨이 있고 밤에는 달이 보이며, 저녁 노을과 밤의 색·밝기가 구분됩니다. 각 친구의 주요 특징과 방 테마를 유지합니다.

이 결과는 검토용 정적 비교 이미지입니다. 생성 과정에서 작은 작화·비례 차이가 있으므로, 각 패널이 정확히 정렬된 실행용 배경이나 애니메이션 자산이라는 뜻은 아닙니다. 이번 작업에서는 앱 코드, 실행용 이미지, 시간대 설정을 변경하지 않았습니다. 이전 v1 시안은 보존했습니다.
