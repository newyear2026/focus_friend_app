# 홈에서 친구 선택 화면을 여는 모습

2026-10-14. 사용자가 앱에서 친구 선택 화면이 어떻게 보이는지 요청해, 홈의 진입 버튼과 열리는 선택 화면을 나란히 배치한 설명 시안을 제작했습니다. built-in ImageGen을 사용했습니다.

- 원본 이미지: [entry-preview.png](entry-preview.png)
- 실제 사용한 전체 프롬프트: [entry-preview.prompt.txt](entry-preview.prompt.txt)

## 실제 첨부한 자료

- 홈: `../character-selection-flow-v1/home.png`
- 친구 선택: `../character-selection-flow-v1/selection.png`

홈 상단 ‘나의 책상’ 옆에 작은 캐릭터 얼굴·‘친구’ 글자·펼침 표시를 하나의 버튼으로 배치했습니다. 이전의 얼굴 아이콘만 있는 진입점보다 목적을 알아보기 쉽도록 글자를 더했습니다. 이 버튼이 별도의 ‘함께할 친구’ 선택 화면으로 이어집니다. 선택 화면에는 다섯 캐릭터와 미리보기 버튼이 있습니다. 하단 내비게이션은 기존 책상·기록·설정 구성을 보여줍니다.

결과를 직접 확인했습니다. 노란 테두리는 홈의 친구 버튼을 정확히 감싸고, 화살표는 오른쪽 선택 화면으로 이어집니다. 노란 강조와 화살표·설명 문구는 이 설명 보드의 주석입니다. 앱에 실제로 표시할 추가 장식이 아닙니다.

‘앱 적용 전 화면 시안’을 표시했습니다. 현재 앱 코드와 데이터는 변경하지 않았으며 캐릭터 선택 기능은 아직 구현하지 않았습니다.
