# 펭귄 · 해달 1차 모션

선택한 두 캐릭터의 2D 원화를 자세별로 제작하고 기존 Flutter 앱에 연결했습니다. 펭귄은 겨울 서재, 해달은 바닷가 방에서 필기·페이지 넘김·찻잔 휴식을 합니다.

## 확인하기

- [집중 / 휴식 미리보기](http://127.0.0.1:8126/docs/design/penguin-otter-motion-v1/) — 두 캐릭터의 동작을 버튼으로 전환합니다.
- 펭귄: [필기·페이지 넘김](penguin-study.mp4), [휴식](penguin-rest.mp4)
- 해달: [필기·페이지 넘김](otter-study.mp4), [휴식](otter-rest.mp4)
- 앱에서는 **친구 → 펭귄 또는 해달 → 미리보기 → 적용**으로 선택합니다. 집중을 시작하면 필기 동작이, 휴식에는 찻잔 동작이 나옵니다.

영상은 앱에서 사용하는 동일한 Flutter Painter로 렌더링했습니다. 집중 영상은 실제 시계 32.4~45.9초의 13.5초 발췌로, 페이지 넘김 앞뒤를 빠짐없이 보여줍니다. 영상 끝에서 처음으로 돌아가는 발췌 재생과 앱의 42.3초 전체 반복은 구분해야 합니다. 휴식 영상은 14초 전체 반복입니다. 재생 속도를 높이지 않았습니다.

## 원화와 타이밍

각 캐릭터마다 집중 원화 24장, 휴식 원화 12장을 만들었습니다. 중복 연필이 있는 집중 7번 원화와 복귀가 급한 일부 휴식 원화는 재생에서 제외했습니다. 휴식은 찻잔을 올린 자세를 역순으로 거쳐 내려옵니다.

| 동작 | 앱 타이밍 |
| --- | --- |
| 필기 | 3.6초 손목 동작을 10회, 총 36초 |
| 페이지 넘김 | 6.3초, 마지막에 필기 기본 자세로 복귀 |
| 집중 전체 반복 | 42.3초 |
| 찻잔 휴식 전체 반복 | 14초 |
| 앱 화면 갱신 / 미리보기 영상 | 약 30fps / 12fps |

방과 책상 소품은 고정된 배경입니다. 필기에서는 얼굴·몸통·꼬리·컵·책 위치를 유지하고 손목과 연필 부분만 바뀝니다. 페이지 넘김에는 어깨와 팔이 연결된 원화를 사용합니다. 얼굴을 두 장 겹치지 않으며, 아래쪽 손·종이 전환에는 부드러운 혼합이 있습니다. 일시정지·앱 비활성 상태에서는 시각 시계도 멈추고 같은 위치에서 재개합니다.

## 생성 및 가공 기록

이미지 제작은 **built-in ImageGen 편집 모드**를 사용했습니다. 기존 캐릭터 장면을 참조해 방의 빈 배경과 투명 원화 시트를 생성했습니다. 원본 출처는 [manifest.json](manifest.json), 요청문은 이 폴더의 `*-study-a.prompt.txt`, `*-study-b.prompt.txt`, `*-rest.prompt.txt`와 공통 방 편집 요청문 [room-plate.prompt.txt](room-plate.prompt.txt)에 있습니다. 생성 원본은 `*-raw.png`로 보관했습니다.

`tool/package_friend_motion.py`는 원화를 다시 그리지 않고 셀 자르기, 동일 비율 크기 조정, 위치 정렬, 아틀라스 포장만 합니다. 집중은 책 표지 왼쪽·아래쪽을, 휴식은 머리 폭·상단을 기준으로 전체 그림을 정렬합니다. 실행 자산은 `assets/images/friends/motion/{penguin,otter}/{room,study,rest}.png`입니다. 그림 한 장의 실행 해상도는 384×384px입니다.

## 검증과 범위

전체 Flutter 테스트와 실제 앱 화면 캡처 테스트 합계 85개 통과, 정적 분석 이상 없음, Android 디버그 빌드 성공입니다. 추가로 최종 영상 렌더링 테스트를 통과했습니다. 업데이트 설치 전후 저장 JSON의 SHA-256, revision 30, 기록 4개, active=null이 모두 같습니다. [검증 기록](design-qa.md), [데이터 보존](data-preservation.json)을 참고하세요.

이번에는 펭귄과 해달을 애니메이션으로 연결했습니다. 다람쥐·사막여우는 정지 장면이며, 랫서팬더의 기존 모션은 유지됩니다. 시간대별 새 방 변형이나 결제 기능은 이 작업 범위에 포함되지 않습니다.

1차 원화 방식이라 페이지를 넘길 때 머리 윤곽에 작은 차이가 있고, 손·종이·컵의 중간 전환에서 부드러운 잔상이 일부 보일 수 있습니다. 필기 몸통 흔들림과 반복 끝의 자세 복귀, 일시정지 자세 보존은 별도 테스트로 확인했습니다.
